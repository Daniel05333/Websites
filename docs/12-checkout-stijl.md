# Checkout in Volkara-stijl (Shopify Basic)

Op Basic kan de checkout niet via het thema of de API worden aangepast (dat is alleen Shopify Plus).
Wel via de checkout-editor: **Instellingen → Checkout → Aanpassen** (knop rechtsboven).

## Branding (penseel-icoon links)

**Logo**
- Upload het Volkara-logo (PNG met transparante achtergrond). Bij een donkere checkout: de witte versie.
- Positie: links · Grootte: middel.

**Kleuren**
| Onderdeel | Kleur |
|---|---|
| Hoofdgebied – achtergrond | `#0E0E0E` |
| Besteloverzicht – achtergrond | `#161616` |
| Knoppen | `#D7261E` |
| Accenten (links, focus, selectie) | `#FF4B32` |
| Fouten | `#FF6A5C` |

Shopify past de tekstkleur automatisch aan voor genoeg contrast. Wil je liever een lichte checkout (sommige kopers vertrouwen dat meer): hoofdgebied `#F7F5F2`, besteloverzicht `#EFEBE6`, knoppen en accenten hetzelfde rood.

**Lettertypen**
- Koppen: **Inter** · Tekst: **Inter**. (Inter Tight en Instrument Serif van de site zitten niet in de Shopify-lijst.)

**Vormgeving**
- Hoekradius: **Klein** (past bij de strakke knoppen op de site).
- Invoervelden: **Gevuld** (filled) met rand.
- Kop/header: optioneel een banner. Gebruik een donkere productfoto (bijv. de pan met vonken), minimaal 1000 px breed.

## Teksten en vertrouwen
- **Instellingen → Checkout**: zet "Bedrijfsgegevens tonen" aan en vul adres, KVK en btw in.
- Beleidspagina's (retour, verzending, privacy, voorwaarden) verschijnen als links onderaan; die staan al in de winkel.

Klik **Opslaan**. Test met een testbestelling of in het voorbeeld rechtsboven (desktop én mobiel).
